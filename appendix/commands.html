nvm install 22

node -v
pnpm -v

七个 lab ​

每个 lab 独立安装。amis / formily / lowcode-engine 使用 --strictPort 锁定端口，端口被占用会直接失败；其余 lab 的端口以终端输出为准。

lowcode-engine 额外有一份 public/vendor（React / Fusion Next / 引擎 UMD），由 predev / prebuild / presmoke 自动从 node_modules 同步，不要手动修改或提交。

lab安装启动构建测试 / 烟测
amiscd labs/amis && pnpm installpnpm dev（5174）pnpm buildpnpm smoke（preview 5274 + 系统 Chrome 截图）
formilycd labs/formily && pnpm installpnpm dev（5175）pnpm buildpnpm smoke（preview 5275 + 系统 Chrome）
lowcode-enginecd labs/lowcode-engine && pnpm installpnpm dev（5176）pnpm buildpnpm smoke（preview 5276 + 系统 Chrome 三章烟测）
tmagic-editorcd labs/tmagic-editor && pnpm installpnpm dev（5177，runtime 同域 iframe 加载）pnpm buildpnpm smoke（preview 5277 + 本机 headless chromium 三章烟测）
grapesjscd labs/grapesjs && pnpm installpnpm dev (5178)pnpm buildpnpm smoke (preview 5278)
capstonecd labs/capstone && pnpm installpnpm dev (5179)pnpm buildpnpm smoke (preview 5279)
mini-lowcodecd labs/mini-lowcode && pnpm installpnpm dev (5180)pnpm buildpnpm test && pnpm smoke (preview 5280)

进阶卷出码验证 ​

bash
cd labs/mini-lowcode
pnpm test          # 五类单测：Schema / 渲染 / 落点 / 历史 / 出码
pnpm build
pnpm smoke         # 设计器：拖入 → 选中 → 撤销 → 导出

CI 与部署 ​

目的命令
查看工作流env -u GH_TOKEN gh run list --repo YZhiJie/lowcode-products-guide --limit 5
查看运行详情env -u GH_TOKEN gh run view <run-id> --repo YZhiJie/lowcode-products-guide
启用 Pagesenv -u GH_TOKEN gh api repos/YZhiJie/lowcode-products-guide-site/pages -X POST -f 'source[branch]=gh-pages' -f 'source[path]=/'
验证线上curl -I https://yzhijie.github.io/lowcode-products-guide-site/

所有 gh / git 写操作前加 env -u GH_TOKEN，避免使用环境里注入的无权限 token。
