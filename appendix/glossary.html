本页收录全套教程反复出现的术语。首次阅读遇到不熟悉的词，可以回到这里建立最小定义，再回正文看上下文。

术语一句话定义出现章节
低代码用配置、模型或可视化操作替代重复编码，产出可运行应用的开发方式00
Schema用结构化数据描述页面、表单或组件树的配置，通常是 JSON00、01、04、16
渲染器读取 Schema 并生成 UI 的运行时；输入是配置，输出是组件树或 DOM07、16、17
设计器让用户通过拖拽、属性面板和画布编辑 Schema 的可视化工具03、07、10、16、18
物料可被设计器拖入、被渲染器识别的组件资产，含组件实现与元信息07、08、17
物料协议描述物料的名称、属性、插槽、默认值与设计态行为的约定08
Setter设计器属性面板里编辑某个字段的控件，例如输入框、选择器、颜色选择器03、08、18
资产包把一组物料及其元信息打包分发的产物，供设计器与渲染器消费08
插件在不改内核的前提下扩展能力的模块，通常通过 setup(api) 注册生命周期09、19
扩展点内核暴露给插件的稳定接口，例如注册组件、注册 Setter、监听 Schema 变化09、19
出码把 Schema 转换成可读、可运行的源代码，例如 Vue SFC 或 React 组件09、20
运行时脱离设计器、只负责解释 Schema 并渲染页面的部分07、10、20
编辑器面向搭建者的部分，包含画布、大纲树、属性面板、工具栏03、07、10、18
画布设计器中承载页面预览与拖拽交互的区域，可能是 DOM 也可能是 iframe07、10、12、18
大纲树以树形结构展示页面节点层级的面板，用于选中、移动、调整嵌套07、18
落点拖拽结束时新节点插入的父节点、索引与相对位置18
命令模式把每次修改封装成可执行、可撤销的对象，记录 do 与 undo19
事务把多次修改合并为一次历史记录，避免一次拖拽产生几十条 undo19
撤销 / 重做基于历史栈回退或恢复编辑操作，通常由命令模式或快照实现13、19
表达式Schema 中用于计算、联动、条件显示的受限脚本片段02、05、17
白名单求值只允许预设语法与函数，禁止 eval 与动态代码执行的表达式求值方式17
数据源页面从接口、静态数据或上下文获取数据的声明式配置02、11
联动一个字段或组件的值变化后，触发其他字段或组件的显示、取值、校验变化02、05
反应式（reactions）Formily 中描述字段间依赖关系的声明式机制05
异步校验需要调用接口或异步计算才能得出结果的字段校验05
自由画布允许像素级拖拽与绝对定位的编辑器形态，典型代表是 GrapesJS12
响应式布局页面随视口尺寸变化自动调整布局，不等于响应式数据13
协议版本Schema 的版本号，用于校验兼容性与迁移16
错误边界渲染子树出错时捕获错误并展示降级 UI，避免整页白屏17
快照某一时刻的完整状态副本，常用于简化版撤销重做19
Monorepo多个包放在同一仓库并共享依赖管理的工程形态；本教程刻意不使用00
lockfile锁定依赖解析结果的清单文件，保证不同机器安装出一致的依赖树00
烟测构建或启动后对关键路径做的最小自动化验证00、15
E2E端到端测试，从用户操作出发验证完整链路15
