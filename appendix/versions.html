版本策略 ​

  1. 核心包安装使用 pnpm add --save-exact，避免默认写入范围。
  2. package.json 中所有直接依赖都写精确版本；不追求「小版本自动升级」。
  3. 升级产品版本时，同步修改 appendix/versions.md 与本表对应的行，并重跑该 lab 的 install/build/smoke。
  4. 不把不同博客、不同版本的代码拼在一起。遇到 API 变化，以 lockfile 中实际安装版本的官方文档为准。
